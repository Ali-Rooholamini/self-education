# Frontend standards — pending discussion

The current setup is Nuxt 4, Vue 3 Composition API, TypeScript, Pinia, Persian content, and an RTL document. The starter uses plain CSS; no component library or CSS framework has been selected.

[UI UX Pro Max](../.agents/skills/ui-ux-pro-max/SKILL.md) is installed as frontend design guidance. Use it for relevant UI/UX tasks while retaining the project's Persian RTL layout, Vazirmatn typography, and existing technology choices. Detailed project-specific standards are still pending discussion.

Future discussions can define component organization, design conventions, state ownership, API access patterns, accessibility requirements, frontend testing, and frontend agent review responsibilities.
