# Shared standards — pending discussion

The project owner plans to define agent workflows and implementation/review standards in future conversations.

The current foundation uses two applications, TypeScript, npm workspaces, a Persian RTL interface, and root-level instructions that consider both apps when a task arrives. These are existing setup choices, not a complete architectural policy.

Topics to agree on later include API contracts, saved learning records, agent responsibilities, code review and validation expectations, and how shared decisions are documented.

App-specific discussion placeholders live in [frontend standards](../frontend/docs/standards.md) and [backend standards](../backend/docs/standards.md).
