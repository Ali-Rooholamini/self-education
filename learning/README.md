# فضای یادگیری

این پوشه منبع اصلی برنامه‌های آموزشی است؛ نقشه‌های راه در پایگاه داده نگهداری نمی‌شوند.

- `roadmaps/react.md`: نسخهٔ بدون تغییر فایل React ارائه‌شده توسط کاربر؛ ۱۵ فاز و checkpointهای پروژه.
- `sources/learning-workflow-brief.fa.md`: ثبت ساخت‌یافتهٔ گفت‌وگوی ارائه‌شده دربارهٔ شیوهٔ آموزش و مسیرهای مکمل.
- `roadmaps/javascript-browser.md`، `performance.md` و `frontend-system-design.md`: برنامه‌های پیشنهادی استخراج‌شده از همان گفت‌وگو؛ برخلاف React، برنامهٔ قطعی تأییدشده نیستند.
- `roadmaps/typescript.md` و `testing.md`: جایگاه مسیرهای فعلی؛ تا دریافت برنامهٔ واقعی، سرفصل ساختگی اضافه نمی‌کنیم.
- `tutor-instructions.md`: قرارداد مربی برای آموزش قدم‌به‌قدم.
- `.local/`: پیشرفت، جلسات، تمرین‌ها، یادداشت‌ها و رونوشت گفت‌وگوهای شخصی در فایل JSON؛ خارج از Git و بدون استفاده از دیتابیس.

React: یکشنبه و سه‌شنبه، ۴۵ تا ۷۵ دقیقه؛ آخر هفته اختیاری. مسیرهای اصلی React، TypeScript و Testing هستند. JS/Browser هفته‌ای یک جلسه، Performance بعد از پایهٔ مرورگر، و System Design حدود هر ۷ تا ۱۰ روز یک case study دارد. این پیشنهاد زمان‌بندی است، نه برنامهٔ اجباری یا تاریخ پیشرفت واقعی.

وضعیت اولیهٔ تمام موضوع‌های واردشده مطابق فایل منبع است. تکمیل موضوع با تأیید خود یادگیرنده و بررسی مفهوم، کاربرد، مقایسه، اشتباهات و تمرین انجام می‌شود. چت یا بازکردن یک درس به‌تنهایی موضوع را تکمیل نمی‌کند.

کتاب‌هایی مانند You Don't Know JS هنوز به پروژه اضافه نشده‌اند. پس از ارائهٔ فایل، فصل‌ها باید به Core / Optional / Later دسته‌بندی شوند؛ هدف تمام‌کردن کتاب نیست، تقویت قضاوت مهندسی است.

برای انتقال رکوردهای شخصی به دستگاه دیگر، هنگام خاموش‌بودن backend از `.local/` نسخهٔ پشتیبان بگیرید. نقشه‌های راه و دستورهای آموزشی در Git قرار می‌گیرند؛ فایل‌های شخصی نه.
